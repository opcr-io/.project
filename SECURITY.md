# Security Policy

## Reporting Security Issues

The Open Policy Containers maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/opcr-io/policy/security/advisories/new) form.

For more details, see the [Open Policy Containers security policy](https://github.com/opcr-io/policy/blob/main/SECURITY.md).
